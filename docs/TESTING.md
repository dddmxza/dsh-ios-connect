# 测试清单

这份文档按「谁动手」分组：A 组全在电脑这边做，B 组要人去碰手机和线，C 组是这台机器上测不出来的。

每条都写了**操作**和**期望**，跑完把结果填进「结果」那一栏。填 `通过` 或写上实际看到的东西。

## 0. 开始之前

手机插线，解锁着，开发者模式开着。然后查 DSH 当前端口（每次重启都会变）：

```powershell
Get-NetTCPConnection -State Listen |
  Where-Object { $_.LocalAddress -eq '127.0.0.1' } |
  Select-Object LocalPort, OwningProcess | Sort-Object LocalPort
```

下文统一用这个变量，把端口换成上面查到的那个：

```powershell
$b = 'http://127.0.0.1:37067/api/dsh-ios-connect'
```

清单里凡是 `GET $b.xxx` / `POST $b.xxx` 的，都指这个前缀。

### B3 锁屏解锁

| | |
|---|---|
| 操作 | 手机锁屏 → 跑 `phone_unlock`（设了密码的情况）→ 再清掉密码跑一次 |
| 期望 | 设了密码：点亮、上滑、输密码、进桌面。没设密码：只点亮 + 上滑 |
| 结果 | **通过**（2026-10-26 复测三次）。`wda/lock` 锁屏 → `phone_unlock` → 六位密码全部进去 → 进桌面，截图确认。 |

> 密码错了不会重试，只回报「密码输完了但停在锁屏」。iOS 自己有失败计数，错五次锁一分钟，别反复试。
>
> 这一条踩了两个坑，都是后来才查出来的：
> 1. **能点亮熄屏的只有 home 键。** `POST /session/{sid}/wda/pressButton {name:"home"}` 之后 source 里 `visible="true"` 从 25 涨到 57；而 `POST /session/{sid}/actions` 注入的 tap 对熄屏屏幕毫无作用。别指望点屏幕叫醒。
> 2. **home 点亮之后先看键盘，别急着上滑。** 很多情况下点亮后人就停在密码界面，键盘自己就在；这时候从底部起手的滑动会被系统当成 home 手势，反而把键盘收回去。实测三种滑法，只有「不滑」那次键盘留着。现在的顺序是：按 home → 等 1 秒 → 查键盘 → 有就直接输，没有才从 0.8h 滑到 0.35h。
> 3. 密码必须**一次读全键位、连着按**。原来每按一位重读一次界面，一次重读要一两秒，按下去时键盘状态还是旧的，结果六位只进去一位、屏幕上只有一个圆点。现在读完一次连按，间隔 380 ms。

### B4 拔线再插回，链路能不能自己恢复

| | |
|---|---|
| 操作 | ready 状态下拔线等 10 秒，插回去，然后直接 `GET $b.frame` |
| 期望 | 理想情况自动恢复。**这一条目前大概率不通过**，因为 startChain 是线性的，没有 keepAlive 重连 |
| 结果 | **通过**（2026-10-26 复测）。拔了插回，第一帧 500，`phase` 随即自己变成 `starting`「正在起隧道」，8100 / 9100 换了新 PID，约 30 秒后回到 `ready`，`/frame` 回 200、1.3 MB。全程没点连接。 |

这条修之前是不通过的，两个毛病：旧路由不会自己断，`phase` 一直骗人说 `ready`；而且完全没有重连。现在 `markLinkLost()` 把 `ECONNRESET / ECONNREFUSED / ETIMEDOUT / EHOSTUNREACH / socket hang up / EPIPE` 判成断线，`kickReconnect()` 在后台重起一次（30 秒防抖），`phone_screenshot` 撞上也走这条，直接回「过十几秒再试」。

顺带挖出一个更阴的问题：DSH 重启之后，插件丢了上一轮那些 go-ios 子进程的句柄，可进程还活着，占着 8100 / 9100 / 28100，新的 forward 绑不上，状态却报「WDA 起来了但连不上」，把人引去查证书。已在 `startChain()` 开头加 `killStaleIos()`：扫这几个端口，用 `tasklist` 确认占用者是 `ios.exe` 才 `taskkill`，别的程序的端口一概不碰。

## 已知缺口

- **断线自愈**：已修并在 B4 复测通过。拔线再插回，约 30 秒自己恢复，不用点连接。
- **残留进程**：已修。起链路前会清掉占着端口的旧 `ios.exe`。DSH 重启过之后最容易撞上这个，表现是「WDA 起来了但连不上」，以前会误导人去查证书。
- **证书过期查不出来**：免费签名七天到期，插件看不出来，只有连接失败时才显形。
- **只支持 Windows x64**：macOS 和 Linux 没做，包里只带了 win32-x64 的 `ios.exe`。
- **侧栏只读**：能看不能点。要在侧栏直接操作手机得另做一层转发。
- **锁屏密码错不重试**：只敲一遍，敲完还停在锁屏就回报，靠人去判断。
